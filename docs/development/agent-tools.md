# Agent workflows and optional tools

The public repository includes the OpenSpec workflow files generated for this project:

| Tool | Project files |
| --- | --- |
| Codex and compatible agents | `.agents/skills/openspec-*` and `.agents/workflows/opsx-*.md` |
| Claude Code | `.claude/skills/openspec-*` and `.claude/commands/opsx/*.md` |

These files cover proposing, exploring, updating, applying, syncing, and archiving changes. They were generated by OpenSpec 1.13.0 and use the `openspec/` directory in this repository. To run them, install the OpenSpec CLI on your own machine using its [installation guide](https://openspec.dev/docs/installation). The Markdown specs and task lists can be read without an agent or CLI.

CodeGraph is an optional local code-navigation tool used in the private development checkout. Its MCP settings, prompt hook, and local index are machine-specific and are not enabled by this repository. Contributors who use CodeGraph can configure it in their own agent settings and build an index from their own checkout.

Plugins installed under a developer's home directory belong to that developer's Codex or Claude installation. They are not project files and are not copied by cloning this repository. The checked-in OpenSpec skills and commands above are the portable project workflows.
