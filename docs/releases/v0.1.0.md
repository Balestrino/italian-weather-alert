# IWA v0.1.0 — internal pilot

This is the first versioned software release of Italian Weather Alert. It provides a local, evidence-linked service for collecting official weather publications and querying regional warnings and municipal measures separately.

## Included

- JSON API and MCP interfaces for municipality discovery, current situation, alert search, document detail and source coverage.
- Versioned original documents and attachments, durable processing jobs, interpretation diagnostics and private source administration.
- Separate backend, private backoffice and an independent public status frontend showing availability, coverage and updating state.
- Tuscany pilot configurations for regional vigilance, criticality/alert and monitoring, plus Calcinaia municipal publications.
- Optional source-scoped local Qwen chat fallback for classification, extraction and linking, with image OCR when supported. Synthetic regression tests and opt-in real-model tests cover text and images.
- Isolated development/staging configuration, production image/digest safeguards, recovery procedures and automatic per-commit changelog enforcement.

## Installation and validation

Use the [developer setup](https://github.com/Balestrino/italian-weather-alert/blob/v0.1.0/docs/development/setup.md) and [environment guide](https://github.com/Balestrino/italian-weather-alert/blob/v0.1.0/docs/operations/environments.md) to run the service locally. Go 1.27.1 is required for native builds; the Compose stack uses PostgreSQL, RustFS and Crawl4AI. Inference requires separately configured provider credentials or a compatible local model server; model weights are not included.

The release checks include Go tests with race detection, vet, command builds, Compose/environment regression checks, isolated integration coverage with a 66% floor and reachable-vulnerability scanning. Real local-model tests are opt-in and are not part of the hosted CI workflows. See [local fallback configuration and tests](https://github.com/Balestrino/italian-weather-alert/blob/v0.1.0/docs/operations/local-llm-fallback.md).

## Known limits

- Source collection remains an internal Tuscany pilot. Public source access and a public MCP endpoint are not enabled; nationwide coverage is a project goal. Candidate municipal configurations require their own observation and acceptance.
- Local chat/image fallback does not supply semantic embeddings. Remote entitlement and dependent embedding recovery remain open work.
- Production activation still requires capacity, backup/restore, routing, image publication and source-readiness checks. This software release does not complete those tasks.
- Interfaces may change before version 1.0. IWA is an unofficial, best-effort tool; original issuing authorities remain the reference for alerts and safety instructions.
